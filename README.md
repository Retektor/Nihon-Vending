# Nihon-Vending
База данных торговых автоматов в Японии, написанная на языке C# с использованием ASP.NET и NHibernate

## Установка проекта
1. Установите необходимые [зависимости](#зависимости)
2. Скопируйте репозиторий с кодом проекта любым удобным способом
3. [Настройте базу данных](#подключение-базы-данных)
4. Используя командную консоль, перейдите в папку `NihonVending` и выполните следующие команды:
   1. `dotnet dev-certs https --trust`. Эта команда создаёт SSL-сертификат для домена localhost, который используется для тестирования HTTPS-подключений
   2. `dotnet run --profile https`. Эта команда запускает проект с HTTPS-подключением. Адрес для доступа к API см. в логах консоли
5. Больше информации про API в [этом блоке](#api).

## Зависимости
- [.NET](https://dotnet.microsoft.com/en-us/download) – официальный набор инструментов для работы с .NET
- [Docker](https://www.docker.com/products/docker-desktop/) – контейнеризатор, необходимый для запуска образа с СУБД и проверки работы с помощью интеграционных тестов
- [Docker Compose](https://docs.docker.com/compose/install/) – утилита для Docker, необходимая для автоматизации создания образа со всеми необходимыми таблицами и данными

## Подключение базы данных
Проект использует **PostgreSQL** – СУБД с клиент-серверной архитектурой.
Для обеспечения работы БД:
1. Скачайте и установите утилиту Docker Compose
2. Отредактируйте файл `.env.example`, подставив туда актуальные данные для работы с PostgreSQL
3. Выполните команду `docker compose up` и образ с СУБД станет доступен на порту 5433 по умолчанию
Помимо таблиц проект по умолчанию содержит в себе тестовые данные. Для дальнейшей информации см. файл `init-db/999-populate-database.sql`.

## Структура проекта
Проект Nihon-Vending состоит из трёх модулей:
1. `NihonVending`: модуль, непосредственно содержащий в себе приложение для работы
2. `NihonVending.UnitTests`: модуль, содержащий в себе юнит-тесты для проверки работоспособности логики
3. `NihonVending.IntegrationTests`: модуль, содержащий в себе интеграционные тесты, проверяющие целостность работы приложения с СУБД.

*ВНИМАНИЕ*: Перед запуском интеграционных тестов не забудьте запустить контейнер с PostgreSQL. Подробнее [здесь](#подключение-базы-данных).

## API
Для взаимодействия с API необходимо использовать браузер или средства, которые умеют отправлять HTTP-запросы: `curl`, `Postman` и др.
По умолчанию проект использует библиотеку Swagger, которая предоставляет веб-интерфейс для взаимодействия.

На данный момент в приложении доступны следующие эндпоинты:

`[GET] /swagger` - веб-интерфейс для отправки запросов

`[GET] /health` - проверяет целостность приложения

`[GET] /api/vending_machines` - вызывает метод `GetAll()`, который возвращает все объекты класса VendingMachine

`[GET] /api/vending_machines/{id}` - вызывает метод `GetById(id)`, который возвращает конкретный объект класса VendingMachine или ответ 404, если объекта с указанным ID не существует

`[POST] /api/vending_machines/{id}` - вызывает метод `Create(request)`, который создаёт и возвращает объект класса VendingMachine при успешном выполнении

`[PUT] /api/vending_machines/{id}` - вызывает метод `Update(request)`, который обновляет данные у объекта класса VendingMachine и возвращает обновлённый объект или 404, если объекта с указанным ID не существует

`[DELETE] /api/vending_machines/{id}` - вызывает метод `Delete(id)`, который удаляет объект класса VendingMachine


Типы данных и ограничения для атрибутов VendingMachine:
```sql
    id        BIGINT NOT NULL,
    name      TEXT NOT NULL,
    latitude  NUMERIC(8, 6) NOT NULL,
    longitude NUMERIC(9, 6) NOT NULL,
    city      TEXT,
    category  TEXT NOT NULL,
    source    TEXT NOT NULL,

    CHECK (latitude BETWEEN -90 AND 90),
    CHECK (longitude BETWEEN -180 AND 180),
    CHECK (category IN (
        'drinks',
        'snacks',
        'other'
    ))
```

Пример тела для POST-запроса:
```json
{
  "name": "Regular Vending Machine",
  "latitude": 34.693165, 
  "longitude": 135.500236,
  "city": "Osaka",
  "category": "snacks",
  "source": "Google Maps"
}
```
